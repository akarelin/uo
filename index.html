Thread Thread

Abstract name for a connected sequence of work items — like up/down/prev/next for edges, the abstract name is never used in text or frontmatter; renderings are Project, Epic, Task, Idea, sites visited, etc. Threads are semantic, more like annotations; contrast uo:Activity, which is grounded in real data.

https://uo.karelin.ai/ontology#Thread
